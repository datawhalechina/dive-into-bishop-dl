# 4.目标检测
前面我们以图像分类任务为例介绍了卷积神经网络。然而，CNN的强大之处不仅在于它能够自动提取局部特征，还在于通过**卷积、池化、正则化**等操作引入了强有力的**归纳偏置**，从而显著提升了模型的**泛化能力**，正是由于这种特性，CNN不再局限于图像分类任务，而是广泛应用于计算机视觉的多个领域：

- **目标检测** 代表模型：YOLO，功能：识别并定位图像中的目标物体。

- **图像分割** 代表模型：FCN、U-Net、Mask R-CNN、SAM，功能：像素级区域划分，广泛应用于医学图像分析、自动驾驶场景理解等。

- **姿态估计** 代表模型：OpenPose，功能：预测人体关键点，实现人体动作识别与分析。

- **三维重建与深度估计** 代表模型：MonoDepth，功能：利用单目图像推断三维结构信息。
    
因此，CNN 已经成为深度学习视觉领域的核心支柱模型之一，其应用远远超出了最初的图像分类任务。

### 4.1 边界框
在一幅图像中，无论是同时存在多类物体还是只有单个物体，目标检测的任务不仅要识别这些物体的类别，还需确定它们在图像中的具体位置。为此，卷积神经网络通过多层特征提取对输入图像进行表征，并对每个目标回归预测边界框与类别。通常，每个检测结果由表示位置与尺寸的边界框向量、目标类别及其置信度共同构成；边界框可用像素坐标或归一化到[0,1]的连续数值表示，常见形式为中心点与宽高(x,y,w,h)或左上角与右下角(x₁,y₁,x₂,y₂)。其中置信度通常表示模型对“该框内存在目标且属于该类别”的综合概率。可从认知角度类比地理解：CNN 的特征响应机制类似于人类视觉的特征提取过程，而边界框预测则类似于视觉对物体的空间捕捉——这一类比有助于直观理解，但应注意其在语义推理与上下文理解方面并不完全等同于人类视觉系统。

虽然卷积神经网络在一定程度上可以类比为人类视觉系统的事物识别过程，但二者在信息利用方式与机制上存在显著差异。CNN主要依赖局部感受野并通过多层卷积逐步扩大有效感受围，更多依赖从训练数据中直接学习表征，属于典型的“现学现用”；而人类视觉则能调用长期记忆与丰富语义知识，实现基于经验的快速识别。与此同时，人类视觉在上下文理解、选择性、少样本学习与对变换的鲁棒性方面远超传统CNN，卷积神经网络在全局语义建模、注意力分配与对抗干扰方面通常需要额外设计比如加入相应的注意力机制或更多训练数据来弥补。为此，可采取迁移学习或半监督、自监督预训练等策略———例如先在大规模有或无标签数据上预训练骨干网络，再在目标检测数据上微调，以提升低层与中层特征的通用性并改善泛化性能。实践中，皮肤病影像等医学视觉任务常采用此类思路即在预训练后微调，并在某些公开评测和受控实验下达到接近专家的性能，但这类结论依赖于具体数据与验证方式，需谨慎外推。

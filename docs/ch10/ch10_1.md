# 1 计算机视觉

卷积神经网络（CNN）能够推动计算机视觉的快速发展，核心原因在于其相较于传统全连接网络具备 **稀疏连接、参数共享、不变性与等变性** 等优势：  

- **稀疏连接**：全连接网络中相邻层的神经元两两相连，参数规模庞大；而 CNN 通过卷积核的局部感受野实现稀疏连接，大幅降低参数量。  
- **参数共享**：同一卷积核在整个图像上滑动并重复使用，使得模型不必为不同位置学习独立参数，从而提升了训练效率与泛化能力。  
- **特征不变性与平移等变性**：卷积核能够捕捉局部像素间的空间相关性，使 CNN 在处理图像的平移、缩放、形变时仍能保持较强的目标识别能力。  

尽管 CNN 在局部特征提取方面表现突出，但其局部感受野的限制也导致对全局空间依赖关系的建模不足。为弥补这一缺陷，可以引入 **Transformer** 架构：其注意力机制能够直接建模长程依赖与全局关系，从而与 CNN 形成互补，提升整体的表征能力。

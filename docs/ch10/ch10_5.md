# 5 图像分割
在语义分割任务中，模型输出通常为形状 $(B, C, H, W)$ 的张量，其中一个通道代表一个类别的概率（通道数量＝图像数据的类别数量），像素点在所有类别通道上对应的值表示其属于各类别的概率，这些概率一般通过softmax（多类别）或 sigmoid（多标签）函数获得，每个像素的预测类别由概率最大的通道决定：

$$\text{Pred}(x, y) = \arg\max_{c} P_c(x, y)$$

其中 $x$ 、$y$ 分别表示输入数据、输出结果，c表示输入数据中所具有的类别数量，$P_c$表示每个类别的概率

在可视化时，可通过不同颜色区分类别区域、绘制边界线或将分割结果叠加在原图上展示。例如当输出通道数为 3（背景、器官、肿瘤）时，模型输出维度为(B, 3, H, W)，最终可视化可将背景设为黑色、器官为绿色、肿瘤为红色。在医学图像分割中，常见输出为2通道（前景与背景）、3通道（背景+器官+病灶）或 N通道（多器官/多病变）等形式。

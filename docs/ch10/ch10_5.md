# 5 图像分割
语义分割任务中，模型输出通常为形状 $(B, C, H, W)$ 的张量，其中一个通道代表一个类别的概率(通道数量＝图像数据的类别数量)，像素点在所有类别通道上对应的值表示其属于各类别的概率，这些概率一般通过softmax或sigmoid函数获得，每个像素的预测类别由概率最大的通道决定：

>**softmax** vs **sigmoid**选择?
>
>激活函数的选择不应只看类别多少，而应看定义的任务类别之间是否互斥。当同一对象、像素只能属于一个类别时（互斥类别），使用 softmax跨类别归一化并配合交叉熵损失；当同一对象、像素可以同时拥有多个标签时（非互斥类别），使用sigmoid逐通道独立并配合二元交叉熵损失。对于存在层级或包含关系的标签例如 “动物” 与 “猫”，通常把它们建模为多标签问题或采用层级分类方法；语义分割通常用softmax。例如，假设识别的一张照片中有两只猫坐在草地上。若任务是互斥分类如类别{猫,狗,草地}，应使用softmax预测单一类别；若任务示非互斥多标签分类如标签{动物,猫,草地}，则使用sigmoid独立预测每个标签是否存在。

$$
\text{Pred}(x, y) = \arg\max_{c} P_c(x, y)
$$

其中， $(x, y)$ 表示图像中像素的二维坐标位置， $c$ 表示类别的索引， $P_c(x, y)$ 表示像素  $(x, y)$  属于第 $c$ 个类别的预测概率。

在可视化时，可通过不同颜色区分类别区域、绘制边界线或将分割结果叠加在原图上展示。例如在医学图像分割中，输出通道数为3即背景、组织、异常时，模型输出维度为 $(B, 3, H, W)$ ，最终可视化可将背景设为黑色、组织为绿色、异常为红色。

对于不同类型的分类任务，需要根据任务特性选择合适的输出激活函数。对于非互斥类别任务即多标签分类问题，通常采用sigmoid函数，该函数将模型输出压缩到[0,1]区间，用以表示样本属于某一类的概率，但由于sigmoid输出的各类别概率相互独立且总和不一定为1，模型无法自动确定分类边界，因此需要人为设定阈值（通常为 0.5）来判定样本是否属于目标类；对于互斥类别任务即多分类问题，通常采用softmax函数，softmax会对所有类别的同一次输出进行指数归一化，使每个类别的概率值均处于[0,1]区间并且所有类别的概率之和为1，由于这种归一化在类别之间引入了竞争机制，每次预测中必然存在一个概率最大的类别，该类别即可直接作为模型的预测结果，因此无需额外设置阈值。

### 5.1 卷积分割
卷积神经网络可用于解决语义分割问题。CNN通常由多个卷积层堆叠而成，每个卷积块包含若干卷积滤波器、归一化层、激活函数，并可配合池化层实现特征降维与平移不变性。浅层卷积主要提取图像的低级特征如边缘、纹理等，而深层卷积在逐步扩大感受野的同时提取更加抽象的高级语义特征。尽管CNN在语义分割中表现优异，但其计算量较大且内部学习机制难以解释即“黑箱”，因此模型的可控性、可解释性与计算效率仍是当前研究的重要挑战。目前，比如DeepLabv3+、U-Net++等基于CNN的改进模型已广泛应用于医学图像分割和自动驾驶视觉感知等计算机视觉领域。

>为什么卷积块中需要归一层？
>
>卷积块中引入归一化层是为了稳定特征分布，加速模型收敛并提高训练的稳定性。具体而言，归一层通过对输入特征进行标准化使其分布更接近均值为0、方差为1的标准分布，减少了不同通道即特征间的尺度差异，从而缓解了网络训练中的内部协变量偏移问题。从几何视角来看，归一化使损失函数的曲面更加平滑，有助于梯度在反向传播中保持稳定，防止梯度消失或爆炸现象，从而使模型能够更高效地收敛并获得更好的泛化性能。


### 5.2 上采样
卷积神经网络常通过多次使用下采样来逐渐增大感受野并降低特征图空间尺寸大小，从而在减少计算量的同时提取更抽象的语义特征。下采样可以采用跨步卷积或池化等方式：跨步卷积通过可学习滤波器在降采样同时保留并建模局部像素关系，但通常引入更多参数与计算；池化如max、avg为网络引入很强的归纳偏置且计算开销较小，但可能丢失位置与细节信息。为缓解细节丢失，可引入注意力机制如SE、CBAM等以及跳跃连接、多尺度融合或空洞卷积等策略。为了让网络输出与原始输入尺寸对齐、便于计算像素级损失，常在解码端使用上采样转置卷积、插值+卷积等并与低层特征融合；实现时需注意上采样方式的伪影、裁剪策略以及信息融合的细节。

处理特征图的过程中，由于转置卷积在上采样过程中可能产生棋盘格伪影，导致特征图局部区域不均匀，从而影响模型的稳定训练与参数更新。因此，卷积神经网络中常采用插值结合卷积作为替代，以在避免伪影的同时有效恢复空间分辨率并融合局部特征。插值加卷积的操作可以分为两个阶段：

#### 阶段一：插值

##### 坐标映射

不管是使用哪一种插值方法，均有对输出像素索引采用从 0 开始，对任意输出像素位置 $(i', j')$（其中 $i'=0,\dots,sH-1$，   $j'=0,\dots,sW-1$  ），设输入特征图为  $X \in \mathbb{R}^{H \times W \times C}$ ，上采样比例为 $s$ ，则任意输出像素 $(i', j', c)$ 对应的输入连续坐标为：

$$
x = \frac{i'}{s}, \quad y = \frac{j'}{s}.
$$

其中 $s$ 为上采样过程中对输入特征图的放大倍数如 $s=2$ 表示尺寸扩大两倍。该映射建立了输出与输入像素位置之间的对应关系，确保后续插值计算能够在输入特征图的连续空间中获取相应的像素值。
> 注意：不同实现\框架对坐标映射有细微差别，会影响精确的坐标映射。  



##### 最近邻插值

最近邻插值通过将输出像素位置映射到输入特征图中距离最近的像素点，从而直接复制该像素值对应的最近邻插值计算公式为：

$$
X'(i', j', c) = X\big( \text{clip}(\text{round}(x), 0, H-1),\ \text{clip}(\text{round}(y), 0, W-1),\ c \big)
$$

其中 ${clip}()$ 表示边界截断函数，用于确保索引落在合法范围内。该方法计算量小、实现简单，但由于仅复制最近的像素值到目标位置，缺乏空间平滑性，容易在上采样结果中产生块状或锯齿伪影。

图

##### 双线性插值

双线性插值在两个坐标方向上执行线性插值令：

$$
x_1 = \lfloor x \rfloor, \quad x_2 = x_1 + 1, \quad
y_1 = \lfloor y \rfloor, \quad y_2 = y_1 + 1,
$$

定义偏移量：

$$
\delta_x = x - x_1, \quad \delta_y = y - y_1, \quad \delta_x, \delta_y \in [0,1).
$$

处理边界取：

$$
x_2 = \min(x_2, H-1), \quad y_2 = \min(y_2, W-1).
$$

双线性插值的标准公式为：

$$
\begin{aligned}
X'(i',j',c) = &
(1-\delta_x)(1-\delta_y)X(x_1,y_1,c) \\
&+ \delta_x(1-\delta_y)X(x_2,y_1,c) \\
&+ (1-\delta_x)\delta_y X(x_1,y_2,c) \\
&+ \delta_x\delta_y X(x_2,y_2,c).
\end{aligned}
$$


###### 性质说明

- 插值权重由空间距离决定，非负且权重和为 1保持仿射不变性，与像素值本身正负无关。
- 对多通道特征图逐通道独立插值。
- 边界处需做索引截断或填充例如复制边界或常数填充以避免越界。


#### 阶段二：卷积
虽然插值操作能够提升特征图 $X'$ 的空间分辨率，但其无法有效建模局部上下文关系与细节特征。因此，在上采样阶段如U-Net的解码路径通常需要将插值后的高层特征与浅层特征进行融合，并进一步通过若干卷积层实现局部特征的重建与语义细化，从而获得更加精确的空间特征表达。

$$
Y = \text{Conv}(X').
$$

其中 $Y$ 表示经过一次上采样过程得到的特征图。

把不含有全连接层的神经网络称为全卷积网络。
### 5.4 U-Net架构
U-Net架构是计算机视觉领域中最具代表性和影响力的基础网络之一，在医学图像分割、目标检测等像素级任务中被广泛应用。最早提出的U-Net由四层编码器、一个瓶颈层以及四层解码器组成，结构作用：

- 编码器部分：通过卷积和下采样操作逐步提取高层语义特征。
- 瓶颈层：连接编码器与解码器，捕获全局上下文信息。
- 解码器部分：通过上采样与跳跃连接逐步恢复空间分辨率，并融合语义与细节特征。
  
在编码器特征提取的过程中随着网络深度增加，提取特征的语义层次升高的同时空间分辨率逐渐降低，导致部分空间细节信息丢失。为在解码阶段尽可能恢复这些空间信息，U-Net引入了跳跃连接到上采样过程中，将具有相同空间分辨率的高层语义特征与对应的浅层特征进行融合，从而在恢复空间细节的同时保留语义信息，实现更精确的像素级预测。

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class Downsample_block(nn.Module):
    def __init__(self, in_channels, out_channels):
        super(Downsample_block, self).__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, padding=1)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, padding=1)
        self.bn2 = nn.BatchNorm2d(out_channels)

    def forward(self, x):
        x = F.relu(self.bn1(self.conv1(x)))
        y = F.relu(self.bn2(self.conv2(x)))
        x = F.max_pool2d(y, 2, stride=2)
        return x, y

class Upsample_block(nn.Module):
    def __init__(self, in_channels, out_channels):
        super(Upsample_block, self).__init__()
        self.transconv = nn.ConvTranspose2d(in_channels, out_channels, 4, padding=1, stride=2) 
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, padding=1)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, padding=1)
        self.bn2 = nn.BatchNorm2d(out_channels)

    def forward(self, x, y):
        x = self.transconv(x)
        x = torch.cat((x, y), dim=1)
        x = F.relu(self.bn1(self.conv1(x)))
        x = F.relu(self.bn2(self.conv2(x)))
        return x

class Unet(nn.Module):
    def __init__(self, args):
        in_chan = 4
        out_chan = 3 
        super(Unet, self).__init__()
        self.down1 = Downsample_block(in_chan, 64)
        self.down2 = Downsample_block(64, 128)
        self.down3 = Downsample_block(128, 256)
        self.down4 = Downsample_block(256, 512)

        self.conv1 = nn.Conv2d(512, 1024, 3, padding=1)
        self.bn1 = nn.BatchNorm2d(1024)
        self.conv2 = nn.Conv2d(1024, 1024, 3, padding=1)
        self.bn2 = nn.BatchNorm2d(1024)
 
        self.up4 = Upsample_block(1024, 512)
        self.up3 = Upsample_block(512, 256)
        self.up2 = Upsample_block(256, 128)
        self.up1 = Upsample_block(128, 64)
        self.outconv = nn.Conv2d(64, out_chan, 1)
        self.sigmoid = nn.Sigmoid()

    def forward(self, x):
        x, y1 = self.down1(x)  
        x, y2 = self.down2(x)
        x, y3 = self.down3(x)
        x, y4 = self.down4(x)

        x = F.dropout2d(F.relu(self.bn1(self.conv1(x))))
        x = F.dropout2d(F.relu(self.bn2(self.conv2(x))))

        x = self.up4(x, y4)
        x = self.up3(x, y3)
        x = self.up2(x, y2)
        x = self.up1(x, y1)
        x1 = self.outconv(x)
        return x1
```

>思考U-Net以及现在的U-Net变体架构，考虑U-Net架构可能存在的问题有哪些？
>
>U-Net及其变体通过跳跃连接将高分辨率的浅层细节特征与低分辨率的深层语义特征进行融合，从而在语义表达与空间构建之间取得平衡。尽管这一设计直观且有效，经典的U-Net架构仍存在一些局限性：简单的跳跃连接即直接拼接后接少量卷积会造成语义层次差，使得不同层级的特征难以充分对齐或被合理加权；标准解码器仅由若干小卷积核构成，其感受野有限难以捕获全局或长程依赖信息，从而影响对大尺度或复杂结构的恢复效果；常用的上采样方式如转置卷积虽然能够实现空间重建，但可能引入棋盘格伪影。

解决办法：

①插值上采样结合卷积重建先采用插值（如双线性或最近邻）实现空间扩展，再通过卷积层提取局部特征，可有效避免转置卷积带来的棋盘格伪影，并增强上采样后的语义恢复能力。

②多尺度特征融合同时整合来自不同深度提取的特征，以补偿上采样过程中的语义稀释，增强模型对多尺度目标的表达能力，典型方法包括 FPN、UNet++等结构。

③引入注意力机制即通过通道注意力或空间注意力自适应地强化关键区域或通道响应，抑制被稀释的背景特征，从而提升重要区域的辨识度。

④在解码器或上采样模块中引入残差连接，可缓解因网络深度导致的梯度消失问题，保证梯度的有效传播，使模型参数在反向传播中得到更充分的更新。

⑤在解码器的多尺度分支上引入深监督机制，通过对中间特征施加辅助损失约束，可促使中间层学习到更具语义表达能力的特征表示，在一定程度上有助于上采样阶段的特征重建与边界细节恢复。更重要的是，深监督通过提供额外的反向传播路径，有效缓解了梯度消失问题，使损失信号能够更充分地传递至浅层网络，从而提升模型训练的稳定性并加快收敛速度。需要注意的是，辅助损失的权重设置与尺度匹配应谨慎设计，以避免对最终输出性能产生负面影响。

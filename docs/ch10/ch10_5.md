# 5 图像分割
语义分割任务中，模型输出通常为形状 $(B, C, H, W)$ 的张量，其中一个通道代表一个类别的概率（通道数量＝图像数据的类别数量），像素点在所有类别通道上对应的值表示其属于各类别的概率，这些概率一般通过softmax或sigmoid激活函数获得，每个像素的预测类别由概率最大的通道决定：

>**softmax** vs **sigmoid**选择?
>
>激活函数的选择不应只看类别多少，而应看定义的任务类别之间是否互斥。当同一对象\像素只能属于一个类别时（互斥），使用 softmax 跨类别归一化并配合交叉熵损失；当同一对象\像素可以同时拥有多个标签时（非互斥），使用 sigmoid 逐通道独立并配合二元交叉熵损失。对于存在层级或包含关系的标签例如 “动物” 与 “猫”，通常把它们建模为多标签问题或采用层级分类方法；语义分割通常用softmax。例如，假设识别的一张照片中有两只猫坐在草地上。若任务是互斥分类如类别{猫,狗,草地}，应使用softmax预测单一类别；若任务示非互斥多标签分类如标签{动物,猫,草地}，则使用sigmoid独立预测每个标签是否存在。


$$
\text{Pred}(x, y) = \arg\max_{c} P_c(x, y)
$$

其中， $(x, y)$ 表示图像中像素的二维坐标位置， $c$ 表示类别的索引， $P_c(x, y)$ 表示像素  $(x, y)$  属于第 $c$ 个类别的预测概率。

在可视化时，可通过不同颜色区分类别区域、绘制边界线或将分割结果叠加在原图上展示。例如在医学图像分割中，输出通道数为3即背景、组织、异常时，模型输出维度为 $(B, 3, H, W)$ ，最终可视化可将背景设为黑色、组织为绿色、异常为红色。

### 5.1 卷积分割
卷积神经网络可用于解决语义分割问题。CNN通常由多个卷积层堆叠而成，每个卷积块包含若干卷积滤波器、归一化层、激活函数，并可配合池化层实现特征降维与平移不变性。浅层卷积主要提取图像的低级特征如边缘、纹理等，而深层卷积在逐步扩大感受野的同时提取更加抽象的高级语义特征。尽管CNN在语义分割中表现优异，但其计算量较大且内部学习机制难以解释，即“黑箱”，因此模型的可控性、可解释性与计算效率仍是当前研究的重要挑战。目前，比如DeepLabv3+、U-Net++等基于CNN的改进模型已广泛应用于医学图像分割和自动驾驶视觉感知中。

# 3 可视化训练好的CNN
本节将会可视化CNN学到的特征图，以观察深度不同的卷积层提取到的不同语义层次的信息。
## 3.1 视觉皮层
根据书中的描述，可以发现哺乳动物的视觉系统与卷积神经网络的工作过程在本质上具有高度的相似性，两者都经历了从低级特征到高级语义信息的逐层提取过程。具体而言，第一层主要负责提取图像的边缘、纹理等低层次特征；在此基础上，哺乳动物的视觉皮层会通过多次递进的特征提取形成更高层次的表征，而卷积神经网络则以上一层的特征图作为输入，继续提取更深层的语义信息。最终生物视觉系统会整合所有特征信息，通过对以往记忆的检索或生成新的记忆来完成对图像的理解；而卷积神经网络则依靠大量的监督或半监督训练，通过概率分布输出中选择最高概率对应的类别作为最终结果。与哺乳动物相比，卷积神经网络存在一定的局限性---它无法像生物系统那样理解并记忆从未见过的事物，因为其认知能力完全依赖于训练数据的分布。

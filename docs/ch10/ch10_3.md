# 3 可视化训练好的CNN
本节将会可视化CNN学到的特征图，以观察深度不同的卷积层提取到的不同语义层次的信息。
## 3.1 视觉皮层
根据书中的描述，可以发现哺乳动物的视觉系统与卷积神经网络的工作过程在本质上具有高度的相似性，两者都经历了从低级特征到高级语义信息的逐层提取过程。具体而言，第一层主要负责提取图像的边缘、纹理等低层次特征；在此基础上，哺乳动物的视觉皮层会通过多次递进的特征提取形成更高层次的表征，而卷积神经网络则以上一层的特征图作为输入，继续提取更深层的语义信息。最终生物视觉系统会整合所有特征信息，通过对以往记忆的检索或生成新的记忆来完成对图像的理解；而卷积神经网络则依靠大量的监督或半监督训练，通过概率分布输出中选择最高概率对应的类别作为最终结果。与哺乳动物相比，卷积神经网络存在一定的局限性---它无法像生物系统那样理解并记忆从未见过的事物，因为其认知能力完全依赖于训练数据的分布。
## 3.2 可视化训练好的滤波器
第一层卷积滤波器对应输入图像的局部区域，因此可以直接将其权重可视化为小图像。这一层的卷积操作本质上是输入图像与卷积滤波器的内积，当匹配度高时激活值也较大。实验发现，CNN第一层滤波器与人类视觉皮层中的Gabor滤波器非常相似，这种相似性并不代表CNN模拟了大脑，而是源于自然图像共有的统计特征，如边缘与方向结构。而后续层的可视化更复杂，因为输入已变为前一层的特征图。通过向网络输入大量图像并观察哪些能激活特定神经元，可以发现CNN呈现层级式特征结构，低层响应边缘与纹理，高层逐渐识别物体部件甚至完整物体。此外，研究者还提出通过优化输入图像来最大化特定神经元激活的“反向可视化”方法，为防止生成异常高频噪声图像，需加入正则化、模糊与像素裁剪等约束，使结果更接近自然图像。

## 3.2 显著图
卷积网络的特征可通过显著性图来可视化，以找出最关键的图像区域。这种方法通常在最后一个卷积层上进行，因为该层仍保留空间位置信息且语义表达最强，Grad-CAM是一种常用的显著性图方法，它首先计算给定类别 $c$ 对应输出单元 $a(c)$ 对最后一层卷积层各通道激活 $a(k)_{ij}$ 的梯度，然后对每个通道的梯度取平均，得到权重 $αₖ$ 表示该通道对类别 $c$ 的重要性。接着，将这些权重与对应通道的激活图 $A(k)$ 加权求和，生成特征图 $L$ ，最终得到的 $L$ 可上采样并叠加到原图上，以热力图形式展示模型关注的区域。

## 3.3 对抗攻击
利用输入图像像素值的梯度也可以用来生成对抗样本，即通过微小且人眼无法察觉的像素扰动使卷积网络产生错误分类。快速梯度符号法（FGSM）是一种典型方法，它根据损失函数 $E(x,t)$ 对输入图像的梯度方向调整每个像素值，从而得到修改后的图像 $x' = x + \text{sign}(\nabla_x E(x,t))$。在这种情况下，网络参数保持不变，而输入图像被有意改变以增加分类误差。尽管这种扰动极小，但却能使网络以极高置信度输出错误类别，暴露出深度网络的脆弱性。这种攻击最初被认为与模型过拟合有关，但研究发现，即使是不同架构的网络或线性模型也会被相同对抗样本误导。此外，现实世界中甚至能制造出物理对抗样本，使正常拍摄的图像同样被误分类。尽管通过修改训练过程可以缓解部分对抗攻击，但更复杂的攻击方法仍难以防御。因此，理解这种现象的本质并开发有效的防御策略，仍是当前深度学习安全研究的关键课题。

## 3.4 合成图像
DeepDream是一种基于卷积网络的图像修改技术，其目标是生成具有夸张特征的合成图像。该方法通过确定网络中某一隐藏层对输入图像响应最强的节点，然后修改图像以增强这些响应。例如，当输入一张云彩图像时，如果某个节点在局部区域检测到类似猫的模式，就会将该区域修改得更“像猫”。具体操作是将图像前向传播到选定层，然后将该层的反向传播 $δ$ 变量设置为节点的预激活值，通过反向传播计算图像像素梯度，再沿梯度方向对图像进行微小修改。该方法可视为通过最大化选定层所有单元预激活平方和的梯度方法，并可通过空间平滑和像素裁剪进行正则化以生成平滑图像。重复多次此过程可得到更强的特征增强效果。DeepDream 可用于处理真实照片，也可从随机噪声生成完全由网络产生的图像。虽然该方法主要用于生成艺术效果图像，但也能提供对训练网络内部工作机制的直观理解。

# 反向传播
反向传播是一种将链式法则以高效的逆向累积形式应用于多层可微网络的算法，用于计算损失函数对各层参数的偏导数，并通过梯度下降类优化器更新参数，从而最小化模型的总体损失。其核心思想可追溯至1970年代初Seppo Linnainmaa提出的反向模式自动微分。在深度学习出现之前，研究者需手动推导并实现这些梯度计算，随着现代深度学习框架（如 PyTorch、TensorFlow 等）的发展，自动微分机制可以在计算图中自动完成梯度的反向传播与参数更新，使反向传播成为神经网络训练过程的基础环节。

反向传播并不是多层神经网络专属的方法。严格来说，它是反向模式自动微的一种实现形式，利用链式法则在计算图上高效地计算标量损失函数对各个可学习参数的梯度。只要模型由可微或几乎处处可微的算子组成，并且损失函数在大多数点上可微，就可以使用反向传播来计算梯度，并结合梯度下降类优化器如 SGD、Adam 等进行参数更新。即使模型中存在少量不可微点（例如 ReLU 在 0 处），也可以通过次梯度、数值光滑或其他近似方法加以处理。这些不可微点在参数空间中通常是测度为零，因此不会对模型训练造成实质性影响。需要注意的是，反向传播的本质是梯度的高效计算机制，而非神经网络特有的算法。它同样适用于各种可微参数模型，如线性回归、逻辑回归、可微控制系统、可微渲染、可微物理模拟以及概率图模型等。其中，线性回归（最小二乘问题）存在解析解，因此通常不必依赖反向传播；但逻辑回归及其他无闭式解的模型往往需要基于梯度的数值优化，因此同样隐含地使用了自动微分的思想。在计算效率方面，反向模式自动微分在输出为标量、参数数量巨大的场景如深度神经网络即输入维度较大，且输出维度小的类似场景中尤其高效，因为它通过向后累积梯度避免了传播过程中间多次显式计算庞大的雅可比矩阵，而当输出维度较大、输入维度较小时，正向模式自动微分则可能更为合适。

综上所述，反向传播是一种通用的自动微分框架，可视为利用链式法则高效传播梯度的算法基础，神经网络只是其最典型的应用之一。在现代科学计算与工程优化中，反向传播的思想已被广泛应用于各种可微问题中，例如机器学习中的模型优化、强化学习中智能体与环境交互的奖励梯度传播、以及可微仿真和控制任务等。

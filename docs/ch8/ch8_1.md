# 反向传播
反向传播是将链式法则以高效的逆向累积形式应用于多层可微网络的算法，用于计算损失函数对各层参数的偏导并通过梯度下降类优化器更新参数，从而最小化模型损失。其思想最早可追溯到1970年代初Seppo Linnainmaa提出的反向模式自动微分，1974 年 Paul Werbos 在论文“Beyond Regression: New Tools for Prediction and Analysis in the Behavioral Sciences”中首次将该方法系统地引入多层神经网络的学习中；随后 Rumelhart、Hinton 与 Williams 于 1986 年在论文“Learning Representations by Back-Propagating Errors”中推广了这一算法，使其成为训练多层感知机（MLP）的核心手段。反向传播过程包括两个阶段：首先进行前向传播，将输入 $x$ 依次通过各层计算得到输出 $a^L$ 及损失 $loss(a^L,y)$ 及对比模型输出结果与真实数据；然后进行反向传播，从输出层开始利用链式法则递推计算每一层的误差项，从输出结果的网络层开始到第一层接受输入的网络层记为 $1,2,...,i$ , 则第 $i$ 层神经网络相应第 $j$ 个参数梯度计算原理为： $\delta^l=∏_{j=1}^{i}\frac{\partial loss}{\partial z^{lj}}$ ，得到参数梯度 $\frac{\partial loss}{\partial W^l}=\delta^l(a^{l-1})^\top$ 、 $\frac{\partial C}{\partial b^l}=\delta^l$ ，并按 $W^l\leftarrow W^l-\eta\frac{\partial loss}{\partial W^l}$ 、 $b^l\leftarrow b^l-\eta\frac{\partial loss}{\partial b^l}$  等规则更新参数。早期研究者需手动推导并编写这些梯度计算，而现代深度学习框架（如 PyTorch、TensorFlow 等）已通过自动微分机制在计算图中自动完成梯度传播与参数更新，使反向传播成为深度学习训练过程的基础。      
     
> 反向传播只适用于多层神经网络训练的过程吗？
>
>许多读者容易误以为反向传播仅适用于多层神经网络的训练。事实上，反向传播的本质是在计算图中利用链式法则高效计算损失函数对各可学习参数的梯度；从更广义的角度来看，它属于反向模式自动微分（AD）。只要模型由可微部分组成，且损失函数在几乎所有点上可微，就可以使用反向传播计算梯度，并结合梯度下降类优化器如SGD、Adam等更新参数。即便模型中存在少量不可微点（如ReLU在0处），实际训练中通常通过次梯度近似、数值光滑或因这些点在参数空间中测度为零，从而不会对训练造成实质影响。由此可见，反向传播并非深度神经网络的专属方法，而是一种适用于任意可微参数模型的通用梯度计算机制如线性回归或逻辑回归等传统模型中，同样可以视为梯度下降求解过程的实现形式，只不过这些模型往往存在解析解，因此不必显式执行完整的反向传播流程。
